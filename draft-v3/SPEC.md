# ナトビーHP v3 実装スペック（テスト版）

作業ディレクトリ: `draft-v3/site/`（公開はしない。ローカル確認用のテストビルド）

## 0. 全体方針

- 参考サイト: https://pantograph.co.jp/ の「雰囲気」に寄せる。**丸パクリは禁止**（レイアウトの型・余白の取り方・英字大見出しの作法だけを踏襲し、独自の配色とコンポーネントで作る）
- 踏襲する要素
  - セクション見出しは「英字大文字（大きめ・トラッキング広め）＋ 日本語（小さめ）」の2段組み
  - セクション間の余白を大きく取る（PC で 120〜160px 程度）
  - カード型グリッド、画像＋テキストのバランス型レイアウト
  - 高コントラストで、企業サイトらしい落ち着き
- **配色は緑系（さわやかで落ち着いた）**。参考サイトの紺・青は使わない。CSS変数で以下を定義して全体で使い回すこと。
  - `--green-900: #123527`（深緑：ヘッダー/フッター/大見出し）
  - `--green-700: #1E6B4E`
  - `--green-500: #2F9E71`（アクセント：リンク・番号・下線）
  - `--green-100: #DCEBE3`
  - `--green-050: #F3F8F5`（セクション背景の交互敷き）
  - `--ink: #16211C`（本文）
  - `--muted: #6B7A73`（補助テキスト）
  - `--white: #FFFFFF`
- フォント: `"Noto Sans JP", "Hiragino Sans", "Yu Gothic", sans-serif`。英字見出しは `"Barlow", "Helvetica Neue", Arial, sans-serif`（Google Fonts の読み込みは可）
- レスポンシブ必須（PC / タブレット / スマホ）。ブレークポイントは 1024px / 768px / 480px
- アクセシビリティ: skip-link、`aria-*`、フォーカスリング、`prefers-reduced-motion` 対応
- 軽いスクロール連動アニメーション（IntersectionObserver でフェードアップ）は入れてよい。派手にしない
- 依存パッケージ・ビルドツールは使わない（素の HTML/CSS/JS のみ）

## 2. ヘッダーとナビゲーション

- ページは実質2枚。**メインは1枚もの**で、ナビは**ハンバーガーメニューのみ**（PC でもハンバーガーを出す＝オーナー指示）
- ヘッダーは固定（sticky）。左にロゴ、右にハンバーガーボタン
- ハンバーガーを押すと**全画面のオーバーレイメニュー**が開く。中身は縦並びで、英字＋日本語の2段表記
  - `INTRODUCE / どういう会社？` → `#introduce`
  - `SERVICE / できること` → `#service`
  - `WORKS / 事例紹介` → `#works`
  - `CONTACT / お問い合わせ` → `#contact`
  - `COMPANY / 会社概要` → `company.html`（**ここだけ別ページ遷移**。区切り線を入れて他と分ける）
- ページ内リンクは**スムーススクロール**。固定ヘッダーの高さ分オフセットする（`scroll-margin-top`）
- メニューを開いている間は背面スクロールをロック。Esc キーと×ボタンで閉じる。リンク押下でも閉じる
- company.html のハンバーガーも同じ中身。ページ内リンクは `index.html#introduce` のように絶対指定にする

## 3. index.html のセクション（上から順）

### 3-1. ヒーロー（見出しラベルなし）

- メインコピー（`<h1>`・大きく・2行で改行）

```
YouTubeで事業を伸ばす、
経営者の右腕。
```

- サブコピー

```
株式会社ナトビーはお客さまの事業課題に寄り添い
YouTubeやインターネットを通じて
新たなビジネスを共に創りあげるパートナーです。
```

- 背景は深緑ベース。写真素材は無いので、**緑のグラデーション＋幾何学的な図形かノイズテクスチャ**で品よく作る（フリー素材の外部読み込みは禁止）
- 下端に小さくスクロール誘導のインジケータを置く

### 3-2. INTRODUCE / どういう会社？（`id="introduce"`）

- セクション見出し: 英字 `INTRODUCE` ＋ 日本語 `どういう会社？`
- メインコピー（`<h3>` 相当・大きめ・2行で改行）

```
SEO対策の
YouTube版をしませんか？
```

- サブコピー（3段落。**原文のまま1文字も変えない**）

```
インターネット経由の集客はもはや当たり前。Google検索でお客さまが見つかるようSEO対策をする会社は増えてきました。

しかし現在、調べものはGoogle検索ではなくYouTubeでする時代。文字だけでなく、顔が見える動画で顧客との信頼関係をつくることがスタンダードになります。

ナトビーは御社のYouTubeチャンネル作りをサポートします。
```

- レイアウトは左に見出し＋メインコピー、右に本文の2カラム（スマホで縦積み）

### 3-3. SERVICE / できること（`id="service"`）

- セクション見出し: 英字 `SERVICE` ＋ 日本語 `できること`
- 3枚のカードをグリッドで並べる（PC 3列 / タブレット以下は縦積み）
- 各カードの構造 = ①小ラベル（制作／戦略／共創）②番号＋タイトル ③本文。番号はアクセント色で大きめに
- **文言は原文のまま**

```
制作
01. 制作代行
御社のチャンネルを代わりにまるっと運用し制作代行します。企画作り、台本執筆、撮影の段取り、動画編集、データ分析までお任せください。

戦略
02. 戦略支援
チャンネルを伸ばすためのコンサルティング、内製化のための担当者教育だけでなく、YouTubeを通した事業全体へのアドバイザリーを行います。

共創
03. チャンネル共創
新たな集客経路の開拓のために新チャンネルをつくります。基本的にレベニューシェア（利益折半）型での運用となります。
```

### 3-4. WORKS / 事例紹介（`id="works"`）

- セクション見出し: 英字 `WORKS` ＋ 日本語 `事例紹介`
- **後から事例を差し替える前提**なので、事例1件＝1コンポーネントとして繰り返せるマークアップにすること（コメントで「ここを複製して事例を追加」と明記）
- いま入れる事例は1件だけ

```
チャンネル運用事例：なるほど地理
```

- 「なるほど地理」の部分だけがハイパーリンク（`https://www.youtube.com/@naruhodo_chiri` ・ `target="_blank"` ・ `rel="noopener noreferrer"`）
- その下に**チャンネルTOPページのはめ込み画像**を置く
  - `img/works/naruhodo-chiri-pc.png` を**ノートPC風のフレーム**に、`img/works/naruhodo-chiri-sp.png` を**スマホ風のフレーム**にはめ込む
  - フレームは画像素材を使わず **CSS だけで作る**（角丸・ベゼル・影・スタンド）。PC が左で大きく、スマホが右下に少し重なる配置。スマホ幅では縦積み
  - **画像ブロック全体を `<a>` で包み**、クリックで同じチャンネルURLへ（別タブ）。ホバーで軽く浮く
  - `alt` は「なるほど地理 チャンネルトップページ（パソコン表示）」「（スマートフォン表示）」

### 3-5. お問い合わせ（`id="contact"`・見出しラベルなし）

- 英字＋日本語のセクション見出しは**付けない**（オーナー指示）
- 深緑の背景に白抜きで、短いリード文とメールへの導線

  - ボタン: `メールで相談する` → `mailto:narubusiness1@gmail.com`
  - ボタン下にメールアドレスをテキストでも表示

- ロゴ（白）、`© 2026 NATOBE Inc.`、`会社概要`（company.html）へのリンク
- 深緑背景

## 6. 受け入れ条件

1. `draft-v3/site/index.html` をブラウザで開くと、ヒーロー → INTRODUCE → SERVICE → WORKS → お問い合わせ → フッターの順に表示される
2. ハンバーガーを押すとメニューが開き、各項目でそのセクションへスムーススクロールする（固定ヘッダーに隠れない）
3. 会社概要だけ company.html へ遷移し、そこからも index の各セクションへ戻れる
4. WORKS のPC画像・スマホ画像・チャンネル名リンクのいずれを押しても `https://www.youtube.com/@naruhodo_chiri` が別タブで開く
5. 1280px / 768px / 390px でレイアウトが破綻しない
6. 配色が緑系で統一され、参考サイトの紺・青が残っていない
7. コンソールエラーがゼロ
